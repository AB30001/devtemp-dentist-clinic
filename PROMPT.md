# Build: Dentist Clinic Landing Page

## Stack
Next.js (App Router), TypeScript, Tailwind CSS

## Design Description
A calm clinic site on soft blue-white surfaces with teal accents and generous whitespace. Display type uses Fraunces; body uses Source Sans 3. Overall vibe: reassuring, professional, easy to book.

## Sections (in order)
1. Header/Nav — Sticky bar with “Nordic Smile Clinic” logo, links (Services, About, Reviews, Contact), primary “Book appointment” button
2. Hero — Brand name as the dominant headline, one supporting sentence about gentle modern dentistry, dual CTAs (Book / View services), soft gradient visual panel on the right
3. Trust bar — Three highlight blocks: years of experience, same-week appointments, insurers accepted
4. Services — Six cards: cleanings, whitening, implants, emergency care, kids visits, check-ups
5. About — Dr. Ingrid Haugen bio + clinic hours/address card
6. Reviews — Three short patient quotes
7. Contact CTA — Dark band with appointment request form (name, email, preferred date)
8. Footer — Address, phone, demo credit

## Content
Use realistic placeholder content for a family dental practice named “Nordic Smile Clinic” on Strandgaten in Bergen.

## Interactions/Behavior
Smooth scroll to section anchors. Mobile hides mid nav links; booking CTA remains. Form is a static demo (`action="#"`) with required name/email.

## Deployment
After building, deploy to Netlify (recommended) or Vercel — connect the repo for automatic builds.
