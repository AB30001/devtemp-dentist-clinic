# Nordic Smile Clinic

Calm dental clinic landing page — services, reviews, and a booking CTA.

## Tech stack

- Next.js (App Router)
- React
- TypeScript
- Tailwind CSS

## Requirements

- Node.js 20+ (recommended)
- npm

## How to use

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

### Other scripts

```bash
npm run build   # production build
npm start       # run the production build
```

## Deploy

Connect this repo to [Netlify](https://www.netlify.com/) or [Vercel](https://vercel.com/). Both work well with Next.js.

From [devtemp.no](https://devtemp.no), you can also use the one-click **Deploy on Netlify** / **Deploy on Vercel** buttons on the template page.
